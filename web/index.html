Lofree Flow84 Hardware & Firmware Notes
  • Preventing OS & browser shortcuts: "Trap hotkeys" blocks browser shortcuts (e.g. Ctrl+S, Ctrl+P, Tab, F1–F12, Alt). To capture OS-level keys (such as Alt+Tab, Escape, and Win/Cmd) without triggering window manager actions, click Lock OS keys to enter fullscreen with Chrome’s Keyboard Lock API (navigator.keyboard.lock).
  • Fn key: Handled entirely inside the keyboard hardware to activate the Fn layer. Does not emit a scancode to the operating system unless remapped.
  • Caps Lock to Ctrl patch: If you flashed the caps-to-ctrl profile, pressing your physical Caps Lock key will register as ControlLeft without toggling the OS CapsLock indicator.
  • Win / Mac toggle: The physical toggle switch on the back selects between Windows and Mac mode. Test your modifier arrangements (Ctrl vs Cmd, Alt vs Opt) to confirm your operating system layout.

How this remapper works

Runs entirely in this browser. Builds, validation and flashing happen locally from the stock firmware you loaded. Flashing talks to the keyboard over WebHID using the same reports and checks as the hardware-tested Linux flasher.

Firmware replacement, not a live remap. Every edit requires a full firmware reflash. Builds change only approved keymap data, required checksums, and one fixed instruction.

Win/Mac switch: stock firmware reloads the keymap from settings storage when switching OS mode, which would undo a flashed layout. Remapped builds retarget that one call (0x1b06a) to the same ROM keymap loader used at boot, so the flashed layout survives the switch and is never written to settings storage. Restoring stock brings back the original behavior.

Keep the USB cable connected throughout flashing or restoration. Only flash when you can tolerate interruption; software recovery is not guaranteed if the keyboard stops enumerating.

Firmware limitations

    Flow84 layout view

    The 84 keys are drawn from the Flow84’s 75% keycap arrangement. Each key is placed on the factory slot whose Windows-layer function matches its keycap legend (Caps Lock → slot 66, the hardware-tested remap). Factory Fn-layer functions agree with the printed Fn legends (F1/F2 brightness, F7–F12 media, Fn+Del lock, Fn+1/2/3, Fn+N/M). This is a label-based placement, not a recovered wiring diagram.

    The remaining 48 factory slots (unused, numpad and other-keyboard entries) appear only in All 132 factory slots.

    Keys shown faded on a Fn layer have the same assignment as the matching base layer.

    Settings

    Profiles

    Profiles and drafts contain only mapping overrides (oe915-remap-v1). They are not VIA/QMK JSON. Downloading, importing, resetting and previewing never flash the keyboard.

    Stock firmware

    Keep the USB cable connected until the job has finished. Do not switch OS mode or disconnect power during the write. A stock restore does not guarantee removal of previously persisted mappings/settings.
